# Plin
A satisfying task list that helps you feel accomplished as you add, manage, and complete your tasks.

## Run in Android Studio

1. Open this folder in Android Studio (**File → Open**).
2. Wait for Gradle sync to finish.
3. Create/start an emulator (**Device Manager**), then press **Run**.

You should see the Plin screen where you can add tasks; they are saved in a local SQLite database on the device.
